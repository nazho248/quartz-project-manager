# Quartz Project Manager - Contexto del Proyecto

## Descripción General

Este es un fork de [Quartz](https://github.com/jackyzha0/quartz) con funcionalidades adicionales para gestión de proyectos, específicamente el **SprintWidget** para tracking de tareas estilo Notion/Kanban.

**Repositorio:** https://github.com/nazho248/quartz-project-manager

## SprintWidget - Componente Principal

### Arquitectura

```
Markdown con tags (#prev, #actual, #next, #backlog, #ganttchart)
        ↓
[SprintWidget Transformer] → Extrae secciones de headings con tags
        ↓                    Guarda en file.data.sprintSections
        ↓
[SprintWidget Component] → Renderiza tabs con contenido
        ↓                   Orden: Last Sprint → Actual → Next Sprint → Backlog
        ↓
[Client Script] → Cambio de tabs, smooth scroll, highlight
```

### Archivos del SprintWidget

| Archivo | Propósito |
|---------|-----------|
| `quartz/plugins/transformers/sprintWidget.ts` | Transformer que parsea el HTML y extrae secciones con tags |
| `quartz/components/SprintWidget.tsx` | Componente Preact que renderiza los tabs |
| `quartz/components/styles/sprintWidget.scss` | Estilos del widget (gradientes, tabs, responsive) |
| `quartz/components/scripts/sprintWidget.inline.ts` | Script cliente para interactividad |

### Configuración

**quartz.config.ts** - El plugin debe estar en transformers:
```typescript
plugins: {
  transformers: [
    // ... otros plugins
    Plugin.SprintWidget(),
  ],
}
```

**quartz.layout.ts** - El componente debe estar en beforeBody de ambos layouts:
```typescript
export const defaultContentPageLayout: PageLayout = {
  beforeBody: [
    Component.SprintWidget(),
    // ... otros componentes
  ],
}

export const defaultListPageLayout: PageLayout = {
  beforeBody: [
    Component.SprintWidget(),
    // ... otros componentes
  ],
}
```

### Opciones del Transformer

```typescript
Plugin.SprintWidget({
  prevTag: "prev",          // Tag para "Last Sprint" (default)
  actualTag: "actual",      // Tag para "Actual" (default)
  nextTag: "next",          // Tag para "Next Sprint" (default)
  backlogTag: "backlog",    // Tag para "Backlog" (default)
  ganttChartTag: "ganttchart", // Tag para forzar mostrar widget (default)
  maxDepth: 4,              // Máximo nivel de heading a procesar (h1-h4)
})
```

### Opciones del Componente

```typescript
Component.SprintWidget({
  showOnIndex: true,        // Mostrar en páginas index (default)
  defaultTab: "actual",     // Tab activo por defecto
})
```

## Cómo Funciona el Transformer

1. **Búsqueda de Tags**: El transformer busca headings (h1-h4) que contengan tags: `#prev`, `#actual`, `#next`, `#backlog`
2. **Conversión OFM**: Obsidian Flavored Markdown convierte `#tag` a `<a href="/tags/tag">`, el transformer detecta ambos formatos
3. **Extracción de Contenido**: Extrae todo el contenido desde el heading hasta el siguiente heading del mismo nivel o superior
4. **Serialización**: Convierte el contenido HAST a HTML string para renderizado

## Cómo Funciona el Componente

1. **Condiciones de Renderizado**:
   - Páginas index (`slug === "index"` o `slug.endsWith("/index")`)
   - Páginas con `#ganttchart` en algún heading
   - Páginas con `sprintWidget: true` en frontmatter

2. **Separación por Tipo**: Las secciones se dividen en 4 tabs en orden: "Last Sprint" → "Actual" → "Next Sprint" → "Backlog"

3. **Navegación**: Cada sección tiene un botón para scroll suave al heading original

## Estructura del Contenido

El contenido se gestiona como **submodule** Git separado:
- La carpeta `content/` tiene su propio `.gitignore` que ignora todo excepto él mismo
- El contenido personal NO se sube al repo de Quartz
- Para producción, usar submodule o symlink al contenido real

## Notas Técnicas

- El widget usa `dangerouslySetInnerHTML` para renderizar el contenido HTML extraído
- Los checkboxes de Obsidian Tasks se preservan con sus estados
- Los wikilinks ya están procesados por OFM antes de llegar al transformer
- El CSS usa variables de Quartz (`--light`, `--secondary`, etc.) para consistencia de tema
